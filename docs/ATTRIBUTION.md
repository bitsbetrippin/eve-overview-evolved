## Original concept and implementation

The original concept and base application came from
[Eve-Ratting](https://github.com/psychojf/Eve-Ratting), by
[@psychojf](https://github.com/psychojf). Eve-Overlay-Evolved builds on its
log reader, fleet and character dashboards, session metrics, themes,
alerts, history, loot tools and detached overlays.

The starting upstream commit was
`9e3cd612af5d1f7d078c746ac2703c6c19c4b9f1` (upstream `V6.3`).
The Evolved **v0.6** tag uses this project's version series; it does
not renumber the original Eve-Ratting releases.

Original source comments and notices remain. Bundled Python, Tcl/Tk
and dependency credits/licenses remain with their components; see
[THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt).
