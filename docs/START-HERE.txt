EVE-OVERLAY-EVOLVED v0.8.0

1. Extract All from Eve-Overlay-Evolved-v0.8.0-Windows-x64.zip.
2. Open the extracted folder.
3. Double-click START.bat.
4. If only the fleet overview appears, click SHOW PANELS.
5. Press Play on a character dashboard to track new combat hits.

Python, Tkinter and dependencies are included. No Python installation,
admin access, PATH changes or first-run package downloads are needed.
For Windows 10/11 on Intel/AMD 64-bit PCs. Keep all files together.

Aqua TARGET DPS: latest target hit in the combat log.
Red TOP INCOMING DAMAGE: top three attackers over the last 15 seconds.
Amber INCOMING CAP DRAIN: combined neutralizer + Nosferatu GJ this session,
15-second GJ/sec, separate NEUT/NOS totals and top sources by combined GJ.
Hover for each source's split and last module.
Hover a damage attacker for its full name and damage total.
Stop freezes all meters; Reset clears them. Target selection without
landing a hit cannot update the target shown by this log-based app.

Settings detect Documents/OneDrive EVE log folders. Saved custom log
paths are preserved and can be changed in Settings.
Quit using the X on the fleet overview. A character's X hides that
dashboard. The console remains open while the app runs.

UPGRADING
Close the old app. From v0.7.7 and earlier, copy the old root ratting_config.json
and ratting_history.json into the new data/ folder before launching.
From v0.7.8 and later, copy the existing data/ folder into the new release.
Do not overwrite new source files or the runtime with old versions.

Startup errors remain visible. See data/logs/startup.log if created.
Diagnostic command: START.bat --self-test

Enable Background Monitoring, Apply, then hide dashboards to keep tracking.
OVL controls the separate overlay. Start each pilot with Play first.

ALLIANCE LOGO / ROBOTIC EWAR VOICE (v0.8.0)
Settings > SHOW THE INITIATIVE LOGO > APPLY enables the bundled INIT. logo.
Settings > EWAR SOUND chooses Voice / Beep / Off. Use TEST buttons to preview.
Voice uses your selected clip when you are scrambled / pointed / webbed / jammed.
Other targets (including drones and your outgoing EWAR) use a beep if logged.
Beep mode beeps for both groups; Off mutes both. Personal alerts play first.
Run tracking with Play; enable Background Monitoring when hiding dashboards.
Each effect repeats at most every 10 seconds per personal/nearby group, fleet-wide. Clips are queued,
not mixed together. Personal queued alerts expire after 15 seconds; nearby after 8.
These are log-event warnings, not continuous tackle status.

VOICE STYLE / ALERT VOLUME (v0.8.0)
Settings > VOICE STYLE: Robot / Commanding / Dramatic / News anchor / SamL.
Settings > ALERT VOLUME: Low 100% / Medium 200% / High 300% digital gain.
TEST previews the current selection; APPLY saves it for live alerts.
Applies to Voice and Beep. Peaks are limited; Windows volume is unchanged.
Original synthetic styles, not exact celebrity replicas. No runtime downloads.

SAML VOICE (v0.8.0)
Settings > EWAR SOUND: Voice > VOICE STYLE: SamL > APPLY.
Scrambled / Pointed / Webbed / Jammed use automatic personal-event triggers.
Jammed is live for every voice style, using confirmed "You're jammed by" combat records.
Generic lock failures are ignored. Nearby/outgoing jam detection is not yet supported.
The four WAVs are under app/assets/voices/saml. Full supplied audio is preserved.
All clips support Low / Medium / High volume and offline playback.


BATTLE REVIEW — v0.8.0 BETA
Damage dealt or received starts a fight; 60 seconds without damage saves it.
The top aqua dropdown selects Current or a saved highest single-target 15s peak.
Battle Review below incoming damage independently selects saved attacker peaks
and incoming cap drain. Its amber panel shows peak GJ/s, total loss and NEUT/NOS.
Both views keep live recording and fleet DPS running; select Current to return.
Saved titles show the date and EVE/UTC range. Data lives in data/battles/.
Settings > PURGE SAVED BATTLES clears all character archives after confirmation,
keeping active fights, settings and income history. Pause/Stop/Reset/Quit save
an active fight as [partial]. Cap drain, EWAR and misses alone do not start or
extend fights. Old damage logs are not imported. See USER-GUIDE.md for details.
