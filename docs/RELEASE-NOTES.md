# Eve-Overlay-Evolved v0.8.1 beta — Visual setup guide

A documentation-focused release that makes audio setup easier to follow.

- Add a visual tutorial directly below the main panel explanation in the README.
- Show the Overlay Ratting Window with a red box and arrow pointing to Settings.
- Highlight the Settings controls with numbered steps: **1. SamL**, **2. High (300%)**, **3. Apply**.
- Explain Voice mode, the TEST buttons and running/background monitoring for live alerts.
- Bundle the tutorial images in both the Windows and source packages.

Application behavior is unchanged from v0.8.0; this release updates documentation,
screenshots and version labels. All Battle Review, DPS, cap-drain, fleet and EWAR
features remain available.

Download **Eve-Overlay-Evolved-v0.8.1-Windows-x64.zip**, extract it and run
**START.bat**. Python and dependencies are included. To upgrade from v0.7.8 or
later, close the old app and copy its **data/** folder into the new release.

Validation: all 133 existing regression checks, portable startup, README image
and link checks, and visual inspection of the annotated tutorial.

Contributions: @bitsbetrippin. Original concept/base: Eve-Ratting by @psychojf.
