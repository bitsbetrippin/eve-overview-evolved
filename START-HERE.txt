EVE-OVERLAY-EVOLVED v0.7.5

1. Extract All from Eve-Overlay-Evolved-v0.7.5-Windows-x64.zip.
2. Open the extracted folder.
3. Double-click START.bat.
4. If only the fleet overview appears, click SHOW PANELS.
5. Press Play on a character dashboard to track new combat hits.

Python, Tkinter and dependencies are included. No Python installation,
admin access, PATH changes or first-run package downloads are needed.
For Windows 10/11 on Intel/AMD 64-bit PCs. Keep all files together.

Aqua TARGET DPS: latest target hit in the combat log.
Red TOP INCOMING DAMAGE: top three attackers over the last 15 seconds.
Amber INCOMING CAP DRAIN: combined neutralizer + Nosferatu GJ this session,
15-second GJ/sec, separate NEUT/NOS totals and top sources by combined GJ.
Hover for each source's split and last module.
Hover a damage attacker for its full name and damage total.
Stop freezes all meters; Reset clears them. Target selection without
landing a hit cannot update the target shown by this log-based app.

Settings detect Documents/OneDrive EVE log folders. Saved custom log
paths are preserved and can be changed in Settings.
Quit using the X on the fleet overview. A character's X hides that
dashboard. The console remains open while the app runs.

UPGRADING
Close the old app. Copy ratting_config.json and ratting_history.json,
if present, from the old folder into this folder before launching.
Do not overwrite new source files or the runtime with old versions.

Startup errors remain visible. See startup.log if created.
Diagnostic command: START.bat --self-test

FLEET TARGET DPS: Live 15-second target DPS is shown beside each pilot.
Enable Background Monitoring, Apply, then hide dashboards to keep tracking.
OVL controls the separate overlay. Start each pilot with Play first.

ALLIANCE LOGO / ROBOTIC EWAR VOICE (v0.7.5)
Settings > SHOW THE INITIATIVE LOGO > APPLY enables the bundled INIT. logo.
Settings > EWAR SOUND chooses Voice / Beep / Off. Use TEST buttons to preview.
Voice announces You are scrambled / pointed / webbed for incoming log events.
Run tracking with Play; enable Background Monitoring when hiding dashboards.
Same-type audio repeats at most every 10 seconds fleet-wide. Clips are queued,
not mixed together. These are log-event warnings, not continuous tackle status.

VOICE STYLE / ALERT VOLUME (v0.7.5)
Settings > VOICE STYLE: Robot / Commanding / Dramatic / News anchor.
Settings > ALERT VOLUME: Low 100% / Medium 200% / High 300% digital gain.
TEST previews the current selection; APPLY saves it for live alerts.
Applies to Voice and Beep. Peaks are limited; Windows volume is unchanged.
Original synthetic styles, not exact celebrity replicas. No runtime downloads.

SAML VOICE (v0.7.5)
Settings > EWAR SOUND: Voice > VOICE STYLE: SamL > APPLY.
Scrambled / Pointed / Webbed use the normal automatic incoming-event triggers.
Jammed is included as a TEST preview only; automatic jam detection comes later.
The four WAVs are under assets/voices/saml. Full supplied audio is preserved.
All clips support Low / Medium / High volume and offline playback.
